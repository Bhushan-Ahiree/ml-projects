# 🏠 Indian House Price Prediction

Predict house prices using Machine Learning based on property features such as location, area, bedrooms, bathrooms, furnishing status, and more.

---

## 🎯 Objective

Build an end-to-end regression pipeline that:

- Explores the dataset
- Cleans and preprocesses data
- Performs feature engineering
- Trains regression models
- Evaluates performance
- Saves the trained model
- Deploys the model with FastAPI
